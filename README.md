# EduText Website

This repository contains a simple demonstration website for the **EduText** platform.
It showcases a modern, responsive UI/UX built around a green & white colour palette, with
sections for a landing page, Google login, features overview, local payment methods
and contact information. The site is designed to complement the EduText engine described in
your projects and can be used as a starting point for a full‑fledged SaaS offering.

> **Note:** The current version is a static prototype. You will need to integrate your own
> backend, database and payment gateway to make it production ready.

## Features

- **Responsive design** using vanilla HTML & CSS.
- **Green/white theme** with accent colours matching your brand.
- **Hero section** summarising the value proposition of EduText and deep learning pedagogy.
- **Google Sign‑in** button (via [Google Identity Services](https://developers.google.com/identity/gsi/web/guides/display-button)) with callback handler.
- **Feature grid** describing core benefits: contextual problems, lesson plans, reflective prompts and assessment rubrics.
- **Payment methods** area with local options like OVO, DANA, GoPay and Bank Transfer. A placeholder function demonstrates where to hook in your payment provider (e.g. Midtrans Snap or DOKU).
- **Contact section** listing email, WhatsApp and Instagram handles.

## Getting Started

1. **Install dependencies (optional)**

   This prototype does not require any build tools. Simply open `index.html` in a web browser.

2. **Configure Google Sign‑in**

   - Go to the [Google Cloud Console](https://console.cloud.google.com/apis/credentials) and create an OAuth 2.0 Client ID for a Web Application.
   - Add your development domain (e.g. `http://localhost`) to the authorised JavaScript origins.
   - Copy the generated **Client ID** and replace the `YOUR_GOOGLE_CLIENT_ID` string in `index.html`.
   - Deploy a backend to verify Google tokens and create or update user records (see Google documentation for details).

3. **Integrate a database**

   - Use your preferred backend technology (Node.js, Python, PHP, etc.) to build an API.
   - Connect to a database (PostgreSQL, MySQL, MongoDB, etc.) to store user accounts and payment status.
   - Implement routes to handle user registration/login via Google and to fetch/save content generated by the EduText engine.

4. **Local payment integration**

   - Choose a payment gateway that supports Indonesian payment methods (e.g. **Midtrans**, **DOKU**, **Xendit**).
   - Follow the gateway’s documentation to create payment transactions and embed the payment button or iframe.
   - Replace the `initiatePayment()` function in `script.js` with code that triggers the gateway’s checkout flow.

5. **Customise the content**

   - Update text, images and colours in `index.html` and `style.css` to match your brand.
   - Add additional pages (e.g. dashboard, pricing plans) and components as needed.
   - Incorporate dynamic content (e.g. modules, LKPD, prompts) from your EduText engine by calling your API and rendering the results.

## Deployment

To deploy this site, you can simply host the static files on platforms like Netlify, Vercel or GitHub Pages. For a full application, deploy your backend to a serverless platform or a VPS and configure the domain, SSL certificates and environment variables accordingly.
