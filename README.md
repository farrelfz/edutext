# Edutext UNJ

Landing page starter untuk Edutext UNJ. Repository ini berisi struktur HTML/CSS/JS yang siap
 dikembangkan di GitHub.

## Struktur Project

- `index.html` — Struktur halaman utama.
- `styles.css` — Styling modern untuk layout dan komponen.
- `main.js` — Interaksi sederhana untuk form kontak.

## Menjalankan lokal

Gunakan salah satu opsi berikut:

```bash
python -m http.server 8000
```

atau jika memakai Node:

```bash
npx serve .
```

Buka `http://localhost:8000` di browser.

## Pengembangan berikutnya

- Hubungkan form kontak ke API backend.
- Tambahkan halaman login dan dashboard.
- Integrasikan sistem LMS kampus.
